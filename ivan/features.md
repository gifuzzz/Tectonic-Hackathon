the word file is used to mean folder or file in the description bellow

here is all the data you can add to a fille  
- #companies: list of companies about which this file is relevant
- #source: where this file came from (e.g. "Italian Gvt.", "HR", "Company A")
- #file_tags: e.g. "law", "contract", "data", "summary of <file>", "distillation of <file>", "template for <term>" (term example" 401K Annual Contribution)
- #validity: a dropdown that an employee can click to change a file to "invalid" (invalid), "old" (yellow color), "useful" (green color), "awaiting replacement" (blue color)
- #notes: a list of notes that people can write on the file (e.g "section 8 is no longer in action")

features:
- #notes:
  - you can add files to notes like "If you are reading this file you will also need to read @appendix7.pdf"
  - you can reply to a note with a note and people can add multiple notes to a file
  - notes also have a #validty drop down
- changes to the state of anything are tracked and displayed (i.e. you can see who and when added a note, or changed the validity to "invalid")
- you can update files and list a version history (not necessary for the file name to remain constant, just the file id)
  - links point to the old version and when you click them you get a warning this file has a newer version
- you can assign people to a Company and that gives them visibility to all files marked with the company tag, same with country tags
- you get in your dashboard a notification from an AI that reads emails, messages and phone calls with suggestions of notes to add or statuses(=validity) to change
